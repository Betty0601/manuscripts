\section{Proofs and Derivations}\label{sec:proofs}

Every result in this section is presented twice: as a \emph{paper-and-pencil
derivation} and as a \emph{formal Lean proof}.

\subsection{Rewriting and decision procedures}
Expanding $(x+1)^2 = x^2 + 2x + 1$ for $x\in\lgZ$ is distributivity followed
by collecting like terms on paper. In Lean the single tactic \texttt{ring}
closes the goal, since the statement is a decidable identity in commutative
rings:

\begin{lstlisting}
example : forall x : Int, (x + 1)^2 = x^2 + 2*x + 1 := by
  intro x
  ring
\end{lstlisting}

\texttt{omega} handles Presburger arithmetic and \texttt{norm\_num} handles
closed numeric goals:

\begin{lstlisting}
example (n : Nat) : n < n + 1 := by omega
example : (2 : Nat) + 2 = 4 := by norm_num
\end{lstlisting}

\subsection{Induction}
We prove $n\cdot 0 = 0$.

\noindent\emph{Paper derivation.} Induct on $n$. The base case
$0\cdot0=0$ holds by definition. In the step case,
$(n+1)\cdot0 = n\cdot0 + 0$ by \texttt{Nat.succ\_mul}; applying the
induction hypothesis $n\cdot0=0$ gives $0+0=0$.

\begin{lstlisting}
theorem mul_zero_demo (n : Nat) : n * 0 = 0 := by
  induction n with
  | zero => rfl
  | succ n ih =>
      -- rw tries rfl after rewriting, so the goal is closed here
      rw [Nat.succ_mul, ih]
\end{lstlisting}

The analogous statement for lists,
$|xs \mathbin{++} ys| = |xs|+|ys|$, can be found in the module
\texttt{Proofs/\allowbreak Induction.lean}.

\subsection{Propositional logic and proof by contradiction}
$\neg\neg P \leftrightarrow P$ holds in classical logic (Mathlib defaults to
classical logic). The listing below uses the ASCII spellings \texttt{Not}
and \texttt{<->}:

\begin{lstlisting}
example (P : Prop) : Not (Not P) <-> P := by
  constructor
  case mp =>
    intro h
    by_contra hn
    exact h hn
  case mpr =>
    intro h
    intro hn
    exact hn h
\end{lstlisting}

\subsection{Search: search before you prove by hand}
\texttt{exact?}, \texttt{rw?}, and \texttt{apply?} query the Mathlib
library~\cite{Mathlib2020} for existing lemmas, while \texttt{decide}
evaluates closed decidable goals directly. In formalisation work, reach for
the search tools first and write long proofs only when they fail.
