\section{PQC and Cryptography Exercises}\label{sec:pqc}

\subsection{Finite fields}
When $p$ is prime, $\lgZ/p\lgZ$ is a finite field, represented in Lean by
\texttt{ZMod p}. A \texttt{Fact (Nat.Prime p)} witness has to be registered
for a concrete literal prime (the standard idiom):

\begin{lstlisting}
instance : Fact (Nat.Prime 7) := Fact.mk (by decide)
#check (inferInstance : Field (ZMod 7))
example : (5 : ZMod 7) * 6 = 2 := by decide
\end{lstlisting}

\noindent\textbf{Fermat's little theorem.} For every $a\in\lgF{p}$ we have
$a^p = a$. The formal version at $p=7$ uses \texttt{simp}, which applies
Mathlib's \texttt{ZMod.pow\_card} (namely $a^{|\lgF{7}|}=a$) and reduces the
cardinality to $7$:

\begin{lstlisting}
example : forall a : ZMod 7, a ^ 7 = a := by
  intro a
  simp
\end{lstlisting}

\subsection{The polynomial ring of ML-KEM}
ML-KEM~\cite{FIPS203}, standardised from CRYSTALS-Kyber~\cite{BDKLLPSSS2018Kyber},
operates over $\lgF{3329}[X]/(X^n+1)$. We first establish basic algebraic
facts in the full polynomial ring $\lgF{3329}[X]$:

\begin{lstlisting}
open Polynomial
#check (X : Polynomial (ZMod 3329))

example (p : Polynomial (ZMod 3329)) : p * 0 = 0 := mul_zero p
example (p q r : Polynomial (ZMod 3329)) :
    (p + q) * r = p * r + q * r := add_mul p q r
\end{lstlisting}

\subsection{Counting and growth bounds}
Arguments of the form ``the bad-event space has at most $2^n$ choices'' rest
on the elementary facts $\forall n,\ 0 < 2^n$ and $\forall n,\ 2^n > n$:

\begin{lstlisting}
theorem two_pow_gt : forall n : Nat, 2 ^ n > n
  | 0 => by decide
  | n + 1 => by
      have ih := two_pow_gt n
      simp [pow_succ]
      nlinarith
\end{lstlisting}

\subsection{Numeric cross-validation}
The same algebraic conclusion can be checked symbolically and numerically in
Wolfram. The exported \LaTeX{} fragments generated by
\texttt{common/mathematica/export-tex.wls} are pulled in with
\texttt{\textbackslash input}, keeping the three sides consistent:
\emph{Wolfram experiments} $\leftrightarrow$ \emph{exact Lean statements}
$\leftrightarrow$ \emph{the LaTeX prose}.
